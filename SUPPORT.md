# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/jamesconwaydev/parsec/discussions)
- **Bugs, or something Lexbor does that Parsec doesn't:** [open an issue](https://github.com/jamesconwaydev/parsec/issues/new/choose)
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't post them in public.
- **Documentation:** [the wiki](https://github.com/jamesconwaydev/parsec/wiki)

Parsec hasn't had a release yet, so expect rough edges and the occasional
breaking change before 1.0.
